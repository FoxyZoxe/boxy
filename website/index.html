◈ CAPACITÉS

Tout ce que Boxy peut faire pour vous

Un assistant qui évolue avec vous. Configurez ce dont vous avez besoin, ignorez le reste.

🎤

Commandes vocales

Parlez naturellement en français. Boxy comprend, répond vocalement et agit immédiatement. Wake word configurable.

Whisper + Edge-TTS
⚡

Automatisation PC

Ouvrir des apps, régler le volume, gérer des fichiers, copier/coller, exécuter des commandes shell.

Windows natif
🔍

Recherche web

Boxy cherche sur internet et vous synthétise les résultats en une phrase. Pas de navigateur à ouvrir.

DuckDuckGo
👁

Vision par ordinateur

Boxy peut lire votre écran, analyser des images, extraire du texte. "Qu'est-ce qu'il y a sur mon écran ?"

Moondream / GPT-4V
🧠

Mémoire persistante

Boxy se souvient de vos préférences d'une session à l'autre. Nommez-le, personnalisez sa personnalité.

JSON local
🎨

Interface HUD

Interface graphique cyberpunk avec thèmes colorés, mode compact, streaming token par token, tray systray.

PyQt6
◈ MOTEURS IA

Choisissez votre moteur IA

Boxy fonctionne avec trois fournisseurs. Changez en un clic.

GRATUIT
🦙

Ollama

IA 100% locale sur votre machine. Aucune donnée envoyée. Fonctionne hors-ligne.

  • ✓ Mistral, Llama, Gemma…
  • ✓ Zéro frais
  • ✓ Vie privée totale
  • △ Nécessite un bon GPU
mistral:latest
RECOMMANDÉ
⚡

Groq

Cloud ultra-rapide, gratuit sans carte bancaire. Le meilleur rapport vitesse/qualité.

  • ✓ Llama 3.3 70B
  • ✓ Gratuit (console.groq.com)
  • ✓ Réponses instantanées
  • ✓ Suit parfaitement les instructions
llama-3.3-70b-versatile
PAYANT
🤖

OpenAI

GPT-4o mini pour les tâches complexes. Clé API requise.

  • ✓ GPT-4o / GPT-4o mini
  • ✓ Qualité maximale
  • △ ~0,15$/1M tokens
  • △ Carte bancaire requise
gpt-4o-mini
